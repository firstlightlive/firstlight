◇ Rules of the Block
Name it first. Write the ONE thing before the timer starts. If you cannot name it, you are not ready to start — that is a planning problem, not a focus problem.
Phone in the hall drawer. Not face-down, not in the room. Territory rule, same as 7 PM.
Tally, don’t chase. Every time attention breaks, make one mark. Counting it is what kills it — the mark is the whole intervention.
Park it. A thought that isn’t the ONE thing goes in the list → straight back to work. It will still be there at 6:40.
The reset is not a break. It is the thing that makes block 6 as sharp as block 1. Skipping it to “keep going” is how the afternoon dies.
Never two in a row missed. One skipped reset is a slip. Two is a new habit.
