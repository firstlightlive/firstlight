Privacy Policy

Last Updated: June 2026
TL;DR: firstlight.live is a personal accountability journal operated by one individual (Anupam Kumar) for personal use. As a visitor, almost nothing is collected from you — just an anonymous visit count. The personal data on this site is the operator's own data about themselves (training, sleep, food, journals). It is not collected from you and not shared with anyone. If you install the PWA, it runs locally on your device with read-only access to the public site.

1. Who runs this site

This site is operated by one individual:

  • Operator: Anupam Kumar
  • Location: Bangalore, Karnataka, India
  • Contact: firstlightlive@gmail.com
  • Hosted on: Cloudflare (cdn / edge); Supabase (database, EU/US regions)

This is not a company, not a SaaS, not a multi-user platform. There is no other staff, no analytics team, no advertising network, no data-broker partner.

2. What is collected from visitors

2.1 Anonymous visit counter

Each page load increments a counter so the operator can see "X visitors since Day 1." No IP, no user agent, no fingerprint, no cookie is associated with this counter. The increment is server-side, anonymous, and aggregated.

2.2 Comments (only if you choose to comment)

If you submit a public comment, the following is stored: the text you wrote, the timestamp, and the display name you typed. No email, no IP, no account. Comments are stored in the comments table on Supabase.

2.3 Server logs (Cloudflare)

Cloudflare, as the edge provider, may log standard HTTP request data (IP, user agent, path, timestamp) for security and abuse prevention. The operator does not access these logs except for security investigations. Cloudflare's own privacy practices apply: cloudflare.com/privacypolicy.

2.4 What is NOT collected from visitors

  • No advertising cookies, no tracking pixels, no third-party analytics (no Google Analytics, no Meta pixel, no Mixpanel)
  • No email, no name, no phone, no address
  • No payment information (the site does not accept payment from anyone)
  • No location data
  • No browser fingerprinting
  • No cross-site tracking

4. Where the data lives

4.1 Server-side

  • Supabase (Postgres database + Storage). Region: AWS-managed, US/EU. Row-Level Security enforced on private tables.
  • Cloudflare (Workers + static assets). Region: global edge.
  • Google Cloud Storage (archive of older media). Region: US.

4.2 In your browser (if you visit)

  • localStorage: a theme preference (fl_theme), an anonymous visitor identity (fl_visitor_id) used only for the visit counter, optional saved comment-author display name.
  • No cookies are set by this site.

4.3 In your browser (only if you install the PWA)

  • Service Worker cache (fl-shell-v5, fl-supa-reads-v3): stores HTML/CSS/JS shell files for offline use.
  • IndexedDB (fl-sync + fl-auth): stores write queue for offline punches (Operator only) and a PBKDF2 PIN hash (Operator only).
  • sessionStorage: short-lived unlock session token (cleared on tab close).

All locally-stored data can be cleared by uninstalling the PWA and clearing site data (see Section 9 below).

6. Notifications, auto-updates, and other PWA behaviour

6.1 Push notifications

The PWA does not currently send push notifications. If this changes in future, a clear opt-in prompt will be shown at install time and notification permission must be explicitly granted by the user via the browser's standard permission dialog. Notifications can be revoked at any time from browser site settings.

6.2 Auto-updates

The PWA service worker checks for a new shell version on each visit and updates silently in the background. This is a standard PWA behaviour. No code outside the firstlight.live origin is installed, executed, or modified.

6.3 No system modification

Installing the PWA adds an icon to your home screen / app launcher. It does not modify operating-system files, registry entries, browser settings, default search engine, default homepage, or any other system configuration. Uninstalling fully removes the icon and cached data.

6.4 No background activity outside the app

The PWA does not run in the background, does not intercept other apps' traffic, does not collect data from other apps, does not modify other apps. It only runs when you explicitly open it.

7. Data retention

The Operator's personal data is retained indefinitely as part of a long-term personal-accountability archive. Visitor comments are retained until removed by the Operator or upon request from the commenter.

8. Your rights

If you have submitted a comment and wish to:

  • Delete it — email firstlightlive@gmail.com with the comment text and date. It will be removed within 7 days.

If you are a resident of a jurisdiction that grants additional rights (GDPR, CCPA, DPDP), those rights apply and can be exercised by emailing the same address. The Operator is a single individual and will respond within 30 days.

9. How to remove the site from your device

9.1 Uninstall the PWA

  • iPhone / iPad: Long-press the icon → "Remove App" → "Delete App".
  • Android: Long-press the icon → "Uninstall" (or drag to the uninstall area).
  • Mac / Windows / Linux (Chrome/Edge/Brave): Open chrome://apps → right-click "First Light" → "Remove from Chrome".
  • Safari macOS 17+: Right-click the dock icon → "Remove from Dock".

9.2 Clear all locally-cached data

  • Chrome / Edge / Brave: Settings → Privacy & security → Site settings → View permissions and data stored across sites → search "firstlight.live" → Clear data.
  • Safari (Mac): Settings → Privacy → Manage Website Data → search "firstlight" → Remove.
  • Safari (iOS): Settings → Safari → Advanced → Website Data → Edit → swipe "firstlight.live" → Delete.
  • Firefox: Settings → Privacy & Security → Cookies and Site Data → Manage Data → search "firstlight" → Remove Selected.

This clears localStorage, IndexedDB, service worker cache, and any other site-scoped storage.

9.3 Revoke third-party connections (Operator only)

If you are the Operator and want to disconnect linked accounts:

  • Strava: strava.com/settings/apps → revoke "FirstLight"
  • Instagram / Meta: accountscenter.facebook.com/apps_and_websites → remove app

10. Security

The Operator follows reasonable security practices:

  • HTTPS everywhere; HSTS preload
  • Content-Security-Policy, X-Content-Type-Options, X-Frame-Options, Referrer-Policy, Permissions-Policy headers
  • PIN protected by PBKDF2 (200,000 iterations, SHA-256, random salt) before storage in IndexedDB
  • Supabase Row-Level Security on private tables; sensitive secrets restricted to the database's service role only
  • API tokens stored server-side, never bundled in client JavaScript

No system is perfectly secure. If you believe you have found a vulnerability, please email firstlightlive@gmail.com in good faith before public disclosure.
