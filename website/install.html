Personal accountability journal · Works offline · No app store · No payment
What this is: a single-user training and accountability journal operated by one individual. Read-only for visitors. The Operator's daily-write screens are gated by a private PIN.

What this is NOT: not gambling, not wagering, not a financial service, not a marketplace. ₹ amounts shown on the public site are self-imposed personal commitments paid by the Operator to themselves — no external party receives or holds money. No payment is collected from you for installing or using this app.
▸ WHAT THIS APP DOES
  • Shows the public site offline. Cached HTML, CSS, and JavaScript for the firstlight.live homepage, streak page, Strava page, and other public pages.
  • Operator-only: a daily-punch screen and a full command-center admin app, gated behind a PIN that only the Operator knows.
  • Stores locally: a theme preference, an anonymous visit identity, the Operator's cached read data (only if you ARE the Operator). All site-scoped — never used by any other site.
  • Does not collect: visitor email, name, IP fingerprint, location, payment, contacts, microphone, camera, or browser history.
  • Auto-updates: when a new shell version is published, the service worker refreshes silently. No download prompt, no system files modified.
  • Sends emails to the Operator only. Daily and weekly summaries to firstlightlive@gmail.com. Visitors are never emailed.
  • Easy to remove — see the "Uninstall" section near the bottom of this page.

↺ HOW TO UNINSTALL
1
iPhone / iPad: Long-press the icon on your home screen → Remove App → Delete App.
2
Android: Long-press the icon → Uninstall (or drag the icon to the uninstall area).
3
Mac / Windows / Linux (Chrome / Edge / Brave): Open chrome://apps → right-click First Light → Remove from Chrome.
4
Safari macOS 17+: Right-click the dock icon → Remove from Dock.
5
Clear all locally-stored data (cache, IndexedDB, localStorage): Browser Settings → Privacy → Site Data → search firstlight.live → Clear.
6
Removal is complete and permanent. No background process or settings change is left behind.
