🍎 INSTALL ON iPhone / iPad
1
Tap the Share icon ⬆️ in Safari's bottom bar (or top-right on iPad).
2
Scroll down and tap Add to Home Screen ⊞
3
Confirm the name FL Punch and tap Add (top-right).
4
Open from your home screen — unlock with PIN 2 2 5 9 and you're in.
Why no one-click install? Apple intentionally blocks programmatic install on iOS — only the Safari Share → Add to Home Screen path works. Same for Chrome/Firefox on iOS (they're all Safari underneath).
🤖 INSTALL ON Android
1
Tap the ⚡ INSTALL THIS APP button above (if active) — Chrome will pop up its install sheet.
2
Or: tap Chrome's ⋮ menu → Install app.
3
Confirm. Icon appears on your home screen + app drawer.
4
Open it — unlock with PIN 2 2 5 9.
💻 INSTALL ON Mac / Windows / Linux
1
Tap ⚡ INSTALL THIS APP above — works in Chrome, Edge, Brave, Arc, Vivaldi.
2
Or look for the install icon ⊕ in the address bar.
3
App opens in its own window with the cyan header. Pin it to dock/taskbar.
4
Unlock with PIN 2 2 5 9. Change it from Settings once verified.
Safari on Mac? Safari 17+ supports Add to Dock: File → Add to Dock. Older Safari: open via Chrome/Edge for full PWA features.
