## MASTER PROMPT: Slide 1 Generator

Use this prompt every day. Just change the variables in [brackets].

```
You are a graphic design assistant for an Instagram fitness accountability brand called "First Light" (@firstlightlive).

CONTEXT:
- I post a 5-slide carousel every day documenting my daily routine: 5K run + gym + food code, all before 6 AM.
- I have a public bet: if I miss even 1 day, I pay ₹15,000 ($200) to the first follower who comments.
- Today is Day [DAY_NUMBER]. I have [ZERO/NUMBER] misses. The unclaimed total is ₹[AMOUNT].
- Today's story: [DESCRIBE TODAY'S UNIQUE ANGLE — e.g., "slept only 3.8 hours", "Ekadashi fasting day", "ran in heavy rain", "hit a new 5K PR of 28 minutes", "almost didn't wake up"]

DESIGN SPECIFICATIONS:
- Aspect ratio: 4:5 portrait (1080 x 1350 px)
- Background: My gym selfie or running photo (I will provide the image)
- Dark gradient overlay from bottom: starts at ~60% height, reaches 90-95% opacity at the bottom
- Color palette: Gold/Amber (#D4A017) for hero text, White for secondary, Muted gray for tertiary
- Brand: "FIRST LIGHT" in red (#E04040) serif bold, top-left corner
- Day badge: "DAY [NUMBER]" in small rounded pill, top-right corner

TEXT HIERARCHY (this is critical — follow this exact reading order):

TIER SYSTEM — choose the correct tier based on today's day number:

### TIER A: REGULAR DAYS (Day 1-99, except milestones)
| Priority | Text | Style | Size |
|----------|------|-------|------|
| Level 1 (Hero) | ₹15,000 | Gold (#D4A017), heaviest weight | ~72-80pt equivalent, largest on slide |
| Level 2 (Stakes) | IF I MISS EVEN 1 DAY | White, bold caps | ~24-28pt |
| Level 3 (Story teaser) | [Today's unique story in 8-12 words] | White or light cyan, regular weight | ~16-18pt |
| Level 4 (Streak) | [X] days · zero misses | Muted white (60-70% opacity) | ~14pt |
| Badge | DAY [X] | White on semi-transparent dark pill | Small, top-right |
| CTA | SWIPE FOR PROOF → | White text in subtle bordered box | Small, bottom-right |

### TIER B: MILESTONE DAYS (Day 50, 75, 100, 150, 200, 250, 300, 365, 500)
| Priority | Text | Style | Size |
|----------|------|-------|------|
| Level 1 (Hero) | [MILESTONE NUMBER] | White or Gold, heaviest weight | ~120-150pt, dominant |
| Level 2 (Subtitle) | [MILESTONE LABEL — see table below] | Gold or White (opposite of hero) | ~28-32pt |
| Level 3 (Stakes) | ₹15,000 on the line. Zero misses. | White, medium weight | ~18-20pt |
| Level 4 (Story teaser) | [Today's unique story] | Muted white | ~14-16pt |
| CTA | SWIPE FOR PROOF → | White bordered box | Small, bottom-right |

MILESTONE LABELS:
- Day 50: "HALF CENTURY"
- Day 75: "THREE QUARTERS"
- Day 100: "TRIPLE DIGITS"
- Day 150: "FIVE MONTHS"
- Day 200: "TWO HUNDRED"
- Day 250: "UNSTOPPABLE"
- Day 300: "THREE HUNDRED"
- Day 365: "ONE YEAR. EVERY. SINGLE. DAY."
- Day 500: "FIVE HUNDRED"

### TIER C: SPECIAL EVENT DAYS (Ekadashi, punishment walk, race day, PR day)
| Priority | Text | Style | Size |
|----------|------|-------|------|
| Level 1 (Hero) | [EVENT HOOK — e.g., "FASTED 24H. STILL RAN."] | White, heaviest weight | ~48-56pt |
| Level 2 (Stakes) | ₹15,000 if I miss. I didn't. | Gold | ~22-26pt |
| Level 3 (Streak) | Day [X] · zero misses | Muted white | ~14-16pt |
| Badge | DAY [X] | Standard pill | Top-right |
| CTA | SWIPE FOR PROOF → | Standard | Bottom-right |

LAYOUT RULES:
1. My face must occupy 50-65% of the frame. Never cover my eyes or forehead with text.
2. All text lives in the bottom 35-40% of the image, over the dark gradient.
3. Text is LEFT-ALIGNED (not centered).
4. No social handles on Slide 1. Those go on the last slide.
5. No date. No "FOLLOW THE JOURNEY". No slide counter (1/5). These waste space.
6. The story teaser line MUST change every single day. It is the element that makes each post unique.
7. Maintain 8-12px spacing between text tiers for breathing room.

WHAT NOT TO DO:
- Never make the day number the largest text (except on milestone days)
- Never use a dark/neon dashboard background instead of a real photo
- Never use more than 3-4 text elements total
- Never add decorative elements, borders, or frames that don't serve the hook
- Never use the same story teaser two days in a row

Generate the slide layout description now for Day [DAY_NUMBER] using Tier [A/B/C].
```

## TIER DECISION FLOWCHART

Ask yourself these questions each morning:

```
Is today a milestone day (50, 75, 100, 150, 200, 250, 300, 365, 500)?
  → YES → Use TIER B (milestone number becomes the hero)
  → NO ↓

Is today a special event (Ekadashi, punishment walk, race, PR, extreme weather)?
  → YES → Use TIER C (event becomes the hero, e.g., "FASTED 24H. STILL RAN.")
  → NO ↓

Use TIER A (₹15,000 is the hero, daily story teaser changes)
```

## CAPTION PROMPT

```
Write an Instagram caption for First Light Day [DAY_NUMBER].

CONTEXT:
- Routine: 5K run + gym + clean food code, all before 6 AM daily
- Today's data: Slept [X] hours, ran [X] km at [TIME] AM, pace [X]/km, [X] BPM, [X] kcal
- Today's angle: [WHAT MAKES TODAY UNIQUE]
- Streak: [X] days, zero misses
- Unclaimed amount: ₹[X]

STRUCTURE (follow exactly):
1. HOOK (under 125 characters — this is all that shows before "more"): Use one of these formats:
   - Shocking stat: "[Sleep hours] hours of sleep. [Distance] run. Before sunrise."
   - Bold claim: "Day [X]. Zero misses. ₹[amount] stays mine."
   - Vulnerable: "I almost didn't get up this morning. [reason]."
   - Question: "What would you do for ₹15,000? I [action] every day to keep mine."

2. MICRO-STORY (80-120 words): Use S.O.A.R. framework:
   - Situation: Set the scene with time and place
   - Obstacle: What almost stopped me
   - Action: What I did anyway
   - Result: The outcome + how it felt

3. KEYWORDS (weave naturally, don't list): morning routine, 5K run, gym motivation, fitness accountability, Bangalore runner, discipline, early morning workout

4. CTA (last line — rotate daily):
   - Mon/Wed: Comment driver → "What's the earliest you've woken up to train? Drop it below."
   - Tue/Thu: Save driver → "Save this. Come back at 6 AM tomorrow to check if I made it."
   - Fri: Share driver → "Send this to someone who needs to hear this."
   - Sat/Sun: Question driver → "Could you do this for [X] days straight? Honest answers only."

TONE: Direct, raw, no motivational clichés. Speak like a soldier reporting from the field, not a life coach. Short sentences. Specific numbers. No emojis in the hook line. 2-3 emojis max in the body.

HASHTAGS (put in first comment, not caption): #morningrunner #5amclub #runstreak #fitnessaccountability #bangalorerunners #ironcovenantchallenge #firstlightlive
```
