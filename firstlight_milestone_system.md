## TIER SYSTEM — 4 Tiers

### TIER A: Regular Days
- **When:** Any day NOT listed below
- **Hero text:** ₹15,000
- **Day number:** Small badge, top-right
- **Frequency:** ~85% of all posts

### TIER B1: Minor Milestones (Every 100 Days)
- **When:** Day 100, 200, 300, 400, 500, 600, 700, 800, 900, 1100, 1200... (every 100)
- **Hero text:** The day number (medium-large)
- **₹15,000:** Moves to supporting text below
- **Milestone label:** Auto-generated (see formula below)
- **Frequency:** ~10% of posts

### TIER B2: Major Milestones (Yearly + Thousands)
- **When:** Day 365, 730, 1000, 1095, 1461, 1826, 2000, 2191, 2557, 2922, 3000, 3287, 3652, 4000, 5000, 6000, 7000, 7305, 8000, 9000, 10000, 10957, 14610, 15000, 18262, 20000, 25000
- **Hero text:** The day number (LARGE)
- **₹15,000:** Supporting text
- **Milestone label:** Custom label from the table below
- **Special treatment:** Different photo location if possible (beach, mountain, sunrise spot — not gym)
- **Frequency:** ~4% of posts

### TIER B3: Legendary Milestones (Once-in-a-lifetime posts)
- **When:** Day 365, 1000, 3652 (10 years), 7305 (20 years), 10000, 18262 (50 years), 25000
- **Hero text:** Day number at MAXIMUM size (fills 40% of slide)
- **Milestone label:** Epic label (see table)
- **₹15,000:** Small text, almost an afterthought — the streak IS the story
- **Special treatment:** Unique photo, unique background, potentially different layout entirely
- **Frequency:** 7 posts total in 68 years

## AUTO-CALCULATION FORMULAS

Use these formulas so the system never needs manual updates:

```
UNCLAIMED AMOUNT = Day Number × 15,000
Format in Indian numbering: X,XX,XX,XXX

IS MILESTONE = Check in this order:
  1. Is it a LEGENDARY day? (365, 1000, 3652, 7305, 10000, 18262, 25000) → TIER B3
  2. Is it a YEARLY day? (Day ÷ 365.25, check if remainder < 1) → TIER B2
  3. Is it a THOUSAND day? (Day divisible by 1000) → TIER B2
  4. Is it a HUNDRED day? (Day divisible by 100) → TIER B1
  5. Is Day = 75 or 150 or 250? → TIER B1
  6. None of the above → TIER A

MILESTONE LABEL FORMULA:
  - If LEGENDARY → Use custom label from table
  - If YEARLY → "[X] YEARS" (calculate: floor(Day ÷ 365.25))
  - If THOUSAND → "[X] THOUSAND DAYS"
  - If HUNDRED (under 10,000) → "[WORD] HUNDRED" (e.g., THIRTY TWO HUNDRED)
  - If HUNDRED (10,000+) → "[NUMBER] THOUSAND [NUMBER] HUNDRED"
  - If 75 → "THREE QUARTERS"
  - If 150 → "FIVE MONTHS"
  - If 250 → "QUARTER THOUSAND"
```

## WHEN TWO MILESTONES COLLIDE

Sometimes a yearly milestone lands near a hundred milestone (e.g., Day 1095 = 3 years, Day 1100 = eleven hundred). Rules:

1. **Yearly always wins over hundred.** Post Day 1095 as B2 "THREE YEARS". Post Day 1100 as regular Tier A.
2. **Legendary always wins over everything.** If Day 365 is both "ONE YEAR" and close to Day 400, the yearly post takes priority.
3. **If two milestones are within 5 days of each other,** post only the higher-tier one. Skip the lower-tier.
